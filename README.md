# POLISH LAB (폴리시랩) - 고객 전용 프리미엄 부분광택 플랫폼

프리미엄 부분광택(Partial Polishing) 및 스크래치 복원 스마트 견적 & 온라인 예약 웹 애플리케이션

## 🌟 주요 기능
1. **차량 부위별 인터랙티브 비주얼 선택기 (SVG Top View / Side View)**
   - 본넷, 앞/뒷범퍼, 앞/뒷도어, 앞/뒤휀다, 루프, 트렁크 등 전 부위 실시간 선택 및 시각적 하이라이트
2. **실시간 스마트 견적 계산 엔진**
   - 차종별 도장 면적 가산율 (경차 ~ 수입 특수도장)
   - 4단계 손상도 심도 (미세스월 ~ 복합손상/페인트묻음)
   - 다부위 자동 패키지 할인 (2개 10% 할인, 3개 이상 15% 할인)
   - 추가 프리미엄 케어 옵션 (유리막 코팅, 유막제거, 헤드라이트 복원, PPF)
3. **비포 & 애프터(Before & After) 정밀 비교 슬라이더**
   - 스크래치 결함면과 미러 광택 복원면의 직관적인 드래그 비교 (본넷, 도어, 범퍼 프리셋)
4. **온라인 예약 & 사진 첨부 신청 시스템**
   - 시공 방식별 스마트 주소 제어 (센터 입고 시 매장 자동 배정 vs 출장 케어 시 방문 주소 필수 입력)
   - 상처 부위 사진 다중 첨부 및 사전 판정 지원
5. **고객 전용 모바일 디지털 견적서 / 영수증 발급**
   - 고유 예약번호(`PL-2026-XXXX`) 부여
   - 카카오톡/문자 공유 텍스트 원클릭 복사 & A4 인쇄 / PDF 저장 최적화
6. **내 예약 & 견적 내역 간편 조회**
   - 로그인 없이 고객명 + 연락처로 실시간 예약 조회
7. **시공 안내 & 개인정보 수집 약관 모달**
   - 수성 듀얼 폴리싱 공법, 복원 범위, 1년 품질 안심 보증 정책 투명 안내

## 💻 기술 스택
- HTML5, Vanilla CSS3 (Dark Luxury Automotive Glassmorphism), Vanilla JavaScript (ES6+)
- Lucide Icons & Pretendard Font
